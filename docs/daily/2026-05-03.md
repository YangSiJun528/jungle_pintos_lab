### Pintos 내용 정리

1. thread가 가지는 pml4는 page table의 주소이다. 프로세스마다 고유하다.


2. Pintos의 user/kernal 메모리 분리 구조

다음과 같이 영역을 분리한다.

```
  0                         KERN_BASE
  |-------------------------|-------------------------|
   user virtual memory       kernel virtual memory
   user가 사용 가능             kernel 전용 
```

`KERN_BASE`보다 큰 주소는 커널이 사용하는 주소이다. 

가상 주소 공간 일부를 kernel 전용 주소로 예약한다.
그 kernel 영역은 모든 process의 page table에서 똑같이 매핑한다.
user mode에서는 권한 때문에 그 영역을 접근하지 못한다.
kernel mode에서는 그 영역을 통해 kernel data와 physical frame을 접근한다.
