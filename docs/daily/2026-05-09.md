### 디버깅 유틸 추가하기

어차피 디버깅 많이 할거, 예전에 개발할 때 쓰던 패턴을 AI한테 시켜서 다 쓰게 하는것도 좋은듯?

1. grepable 하게 prefix 붙이기
2. 모든 분기와 함수 호출 시 출력하게 하기
3. 기본적으로 반복되는 여러 상태 추가하기

이거는 AI 활용하기, 직접 할라면 할 수 있긴 한데... 유틸 느낌이니까.

또 이런건 시간 오래 걸리고, 잘 하려면 시간 더 써야하니까...
