### 일단 코드 돌리면서 어디까지 잡히나 보기

AI한테 물어보니까 v5까지 하면 통과 가능한 간단한 `lazy-anon`이 좋다고 함.

```
make -C "$PINTOS_ROOT/vm" clean
make -C "$PINTOS_ROOT/vm" build/tests/vm/lazy-anon.result
```

이렇게 뜨는거 보면 예시처럼 load_segment()까지는 가고, 그 이후에 실패해서 종료되는 듯 함.

이걸 완성해내면 되는건가...

```
0x000000800421e5b5: load (userprog/process.c:765)
```

### 디버깅 팁

`debug_backtrace()` 로 콜스택 줄력하고

이런 식으로 써서 결과 확인 가능
```
(cd "$PINTOS_ROOT/vm" && backtrace 0x80042194d9 0x800421d19a 0x8004207f0f)
(cd "$PINTOS_ROOT/vm" && backtrace )
```

