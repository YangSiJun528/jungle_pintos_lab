AI 써서 테스트들과 테스트 케이스 요구사항들만 정리해달라고 하기

```
- mmap-write: writable mmap에 쓴 뒤 munmap; 파일에서 다시 읽으면 쓴 내용과 같아야 함.
- mmap-ro: read-only mmap에 쓰면 프로세스가 정상적으로 계속 진행하면 안 됨.
- mmap-exit: child가 mmap에 쓰고 munmap 없이 종료해도 파일 내용이 저장되어야 함.
- mmap-shuffle: 128KB짜리 큰 writable mmap에 반복적으로 접근/수정 가능해야 함. 여러 페이지 lazy loading/write-back 안정성 확인.
- mmap-remove: mmap된 파일을 닫고 삭제해도 매핑된 데이터는 유지되어야 하고, EOF 뒤 페이지 나머지는 0이어야 함.
- mmap-off: page-aligned nonzero offset 매핑 지원. offset 위치의 파일 데이터가 매핑되고, write-back도 offset 위치에만 적용되어야 함.
- mmap-bad-off: page-aligned가 아닌 offset은 실패해야 함.
- mmap-kernel: mmap 주소 범위가 커널 영역에 닿으면 무조건 실패해야 함.
```

오프셋이 정렬되었으니까 검증 추가함.
