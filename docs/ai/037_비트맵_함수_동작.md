# 비트맵 함수 동작

Pintos의 bitmap은 여러 개의 boolean 상태를 bit 단위로 저장하는 자료구조다. 외부에서는 `idx`번째 bit가 `true`인지 `false`인지 다루지만, 내부에서는 `unsigned long` 배열에 여러 bit를 묶어서 저장한다.

VM swap 구현에서는 bit 하나를 swap slot 하나로 보고 사용한다.

```text
swap_table bit 0 -> swap slot 0 사용 여부
swap_table bit 1 -> swap slot 1 사용 여부
swap_table bit 2 -> swap slot 2 사용 여부
...
```

현재 swap 구현에서는 관례적으로 `false`를 빈 slot, `true`를 사용 중인 slot로 본다.

## 생성과 해제

### `bitmap_create(size_t bit_cnt)`

`bit_cnt`개의 bit를 가진 bitmap을 동적 할당한다. 생성 직후 모든 bit는 `false`로 초기화된다.

swap table에서는 swap disk 전체를 page-size slot 개수로 나눈 값이 `bit_cnt`가 된다.

```c
swap_table = bitmap_create (disk_size (swap_disk) / SECTORS_PER_PAGE);
```

### `bitmap_create_in_buf(size_t bit_cnt, void *block, size_t byte_cnt)`

호출자가 미리 준비한 buffer 안에 bitmap을 만든다. `malloc()`을 쓰지 않고, 정해진 메모리 영역 안에 bitmap metadata와 bit 배열을 같이 배치하고 싶을 때 사용한다.

### `bitmap_buf_size(size_t bit_cnt)`

`bitmap_create_in_buf()`에 필요한 buffer 크기를 byte 단위로 계산한다.

### `bitmap_destroy(struct bitmap *b)`

`bitmap_create()`로 만든 bitmap의 내부 bit 배열과 bitmap 구조체를 해제한다. 미리 제공한 buffer에 만든 bitmap에는 사용하면 안 된다.

## 크기 확인

### `bitmap_size(const struct bitmap *b)`

bitmap이 관리하는 bit 개수를 반환한다. byte 수가 아니라 논리적인 bit 개수다.

## bit 하나 조작

### `bitmap_set(struct bitmap *b, size_t idx, bool value)`

`idx`번째 bit를 `value`로 설정한다. `value`가 `true`면 `bitmap_mark()`, `false`면 `bitmap_reset()`을 호출하는 wrapper다.

### `bitmap_mark(struct bitmap *b, size_t idx)`

`idx`번째 bit를 `true`로 만든다.

swap table 기준으로는 해당 swap slot을 사용 중으로 표시하는 의미로 쓸 수 있다.

### `bitmap_reset(struct bitmap *b, size_t idx)`

`idx`번째 bit를 `false`로 만든다.

swap table 기준으로는 해당 swap slot을 다시 빈 slot로 돌려놓는 의미다. 현재 구현에서는 `anon_swap_in()`으로 page를 다시 읽어왔거나 `anon_destroy()`로 page가 사라질 때 호출된다.

### `bitmap_flip(struct bitmap *b, size_t idx)`

`idx`번째 bit 값을 반전한다.

```text
true  -> false
false -> true
```

### `bitmap_test(const struct bitmap *b, size_t idx)`

`idx`번째 bit가 `true`인지 검사한다.

## 여러 bit 조작

### `bitmap_set_all(struct bitmap *b, bool value)`

bitmap 전체 bit를 같은 값으로 설정한다.

### `bitmap_set_multiple(struct bitmap *b, size_t start, size_t cnt, bool value)`

`start`부터 `cnt`개 bit를 `value`로 설정한다.

```text
start = 3, cnt = 4
대상 bit: 3, 4, 5, 6
```

### `bitmap_count(const struct bitmap *b, size_t start, size_t cnt, bool value)`

`start`부터 `cnt`개 bit 중 `value`와 같은 bit가 몇 개인지 센다.

예를 들어 `value == false`로 호출하면 특정 구간 안의 빈 slot 개수를 셀 수 있다.

### `bitmap_contains(const struct bitmap *b, size_t start, size_t cnt, bool value)`

`start`부터 `cnt`개 bit 중 `value`와 같은 bit가 하나라도 있으면 `true`를 반환한다.

### `bitmap_any(const struct bitmap *b, size_t start, size_t cnt)`

해당 구간 안에 `true` bit가 하나라도 있는지 검사한다.

내부적으로는 `bitmap_contains(..., true)`와 같은 의미다.

### `bitmap_none(const struct bitmap *b, size_t start, size_t cnt)`

해당 구간 안에 `true` bit가 하나도 없는지 검사한다.

즉 구간 전체가 `false`면 `true`다.

### `bitmap_all(const struct bitmap *b, size_t start, size_t cnt)`

해당 구간의 모든 bit가 `true`인지 검사한다.

내부적으로는 `false`가 하나도 없는지 확인하는 방식이다.

## 빈 구간 찾기

### `BITMAP_ERROR`

bitmap 탐색 실패를 나타내는 값이다. 실제 값은 `SIZE_MAX`다.

```c
#define BITMAP_ERROR SIZE_MAX
```

탐색 함수가 이 값을 반환하면 조건에 맞는 bit 구간을 찾지 못했다는 뜻이다.

### `bitmap_scan(const struct bitmap *b, size_t start, size_t cnt, bool value)`

`start` 이후에서 `value`와 같은 bit가 `cnt`개 연속된 첫 구간을 찾고, 그 시작 index를 반환한다. 찾지 못하면 `BITMAP_ERROR`를 반환한다.

예를 들어 swap table에서 빈 slot 하나를 찾고 싶으면 다음과 같은 의미가 된다.

```c
bitmap_scan (swap_table, 0, 1, false);
```

```text
0번 bit부터 검사해서 false인 bit 1개짜리 구간을 찾는다.
```

### `bitmap_scan_and_flip(struct bitmap *b, size_t start, size_t cnt, bool value)`

`bitmap_scan()`으로 조건에 맞는 구간을 찾은 뒤, 찾은 bit들을 전부 반대 값으로 바꾼다.

```text
value == false면
  false인 연속 구간을 찾고
  찾은 구간을 true로 바꿈
```

현재 swap out 구현에서 가장 중요한 함수다.

```c
slot = bitmap_scan_and_flip (swap_table, 0, 1, false);
```

의미는 다음과 같다.

```text
1. swap_table에서 false인 bit 하나를 찾는다.
2. 찾은 bit를 true로 바꿔 사용 중 slot으로 예약한다.
3. 그 bit index를 swap slot 번호로 반환한다.
4. 없으면 BITMAP_ERROR를 반환한다.
```

주의할 점은 bit를 바꾸는 동작 자체는 atomic하게 구현되어 있지만, 검사와 설정 전체가 하나의 atomic transaction은 아니라는 점이다. 그래서 여러 thread가 같은 bitmap을 동시에 scan-and-flip할 수 있다면 외부 lock으로 보호하는 편이 안전하다. 현재 swap 구현에서는 `swap_lock`으로 보호한다.

## 파일 입출력

이 함수들은 `FILESYS`가 켜져 있을 때만 선언된다.

### `bitmap_file_size(const struct bitmap *b)`

bitmap 내용을 파일에 저장하려면 몇 byte가 필요한지 반환한다.

### `bitmap_read(struct bitmap *b, struct file *file)`

파일의 앞부분에서 bitmap bit 배열을 읽어온다. 읽은 뒤 마지막 element의 사용하지 않는 bit는 mask로 정리한다.

### `bitmap_write(const struct bitmap *b, struct file *file)`

bitmap bit 배열을 파일의 앞부분에 쓴다.

파일 시스템의 free map 같은 persistent bitmap을 저장할 때 사용된다.

## 디버깅

### `bitmap_dump(const struct bitmap *b)`

bitmap 내부 bit 배열을 hex dump로 출력한다. 사람이 bit 배열 상태를 직접 확인하고 싶을 때 쓰는 디버깅용 함수다.

## swap table에서의 핵심 사용 흐름

현재 anonymous swap에서 bitmap은 다음 흐름으로 쓰인다.

```text
vm_anon_init()
  -> bitmap_create()
      swap slot 개수만큼 bit 생성

anon_swap_out()
  -> bitmap_scan_and_flip(..., false)
      빈 slot을 찾고 사용 중으로 표시

anon_swap_in()
  -> bitmap_reset()
      swap에서 읽어온 slot을 다시 빈 slot로 표시

anon_destroy()
  -> bitmap_reset()
      process 종료 시 아직 swap에 남은 slot을 반환
```

정리하면, bitmap은 swap disk 공간을 직접 저장하는 자료구조가 아니다. swap disk의 각 slot이 비어 있는지 사용 중인지 추적하는 metadata다.
